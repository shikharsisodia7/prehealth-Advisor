   ==================================================

1. Allow the student to select a health profession.
2. Allow the student to select approximately 10–15 schools offering that professional degree.
3. Display each selected school’s required prerequisite courses in a clean list that can be exported to or pasted into Excel.

This is the central product definition.

Everything in the current application must be evaluated against this definition.

The desired product should be:

* Narrow in scope.
* Easy to understand.
* Efficient.
* Completely accurate to the greatest reasonable extent.
* Based on official program information.
* Useful for early academic planning.
* Supportive of advising rather than a replacement for advising.
* Free from misleading admissions predictions.

“What required prerequisite courses do I need to consider when planning for the professional schools that interest me?”
